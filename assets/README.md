# Interface screenshots and animation

These images show the actual desktop interface with fictional sample records and prepared responses. They illustrate the user experience, not live AI or database results. The contact footer is adapted for the portfolio.

- `smp.chat.png`: a parts cross-reference conversation.
- `smp.results.png`: a table of vehicle applications.
- `smp.sql.png`: the query inspection view.

## Browser sample animation

`smp-demo.gif` shows the runnable browser sample with fictional parts and vehicles. It captures a typed reference lookup and a vehicle follow-up, using the offline question planner, shared C# validation code, and browser-local SQLite database. It does not show live generative AI.

The capture uses a tighter layout for readability as a portfolio cover. Typing and result pauses are timed for an approximately 11-second loop; they are not a response-time benchmark.
